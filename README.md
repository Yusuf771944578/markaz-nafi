# مركز الإمام نافع لتعليم القرآن الكريم وتلقي القراءات

موقع تفاعلي (PWA) يعمل كتطبيق على الجوال والكمبيوتر، ويعمل بدون إنترنت بعد أول زيارة.

## التشغيل محلياً
افتح `index.html` في المتصفح، أو انشر المجلد كاملاً على أي استضافة ثابتة
(GitHub Pages / Netlify) كما هو بدون أي بناء.

## الدخول للإدارة
- افتح `.../#admin` أو اضغط 5 مرات على التذييل.
- كلمة المرور الافتراضية: `771944578` (قابلة للتغيير من لوحة الإعدادات).

## الملفات
- `index.html` — الموقع كاملاً (الواجهات + المنطق).
- `logo.png` — شعار المركز.
- `mahktot.png` — مخطوطة المركز (الواجهة).
- `manifest.webmanifest` + `sw.js` + `icon-*.png` — ملفات التطبيق (PWA).
